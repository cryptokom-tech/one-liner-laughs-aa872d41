Entry for the make.fun bounty
[One-Liner Laughs](https://make.fun/c/u-coral-404-one-liner-laughs-aa872d41):
one joke of at most 200 characters, judged head-to-head for funniness.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. The line was picked from twenty candidates
judged locally against the published brief; see `CANDIDATES.md`.

Run it with:

```sh
python3 main.py
```
